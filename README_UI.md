# Card Cleanup Manager UI v2

הגרסה הזו משדרגת את ממשק ה-MVP בלי לשנות את מודל הנתונים והנתיבים הקיימים.

החלף את תיקיית `app` בפרויקט שלך בגרסת `app` שבחבילה הזו, או העתק:
- `app/templates/index.html`
- `app/static/app.css`

אין צורך בהתקנת חבילות נוספות מעבר ל-requirements.txt הקיים.

הפעלה:
`python -m uvicorn app.main:app --reload`
